\# Student Study \& Performance Manager



\## About the Project



Student Study \& Performance Manager is a Python command-line project designed to help students manage their academic information and study tasks.



The project allows the user to manage a student profile, enter marks, calculate percentage and grade, manage study tasks, and view a performance report.



\## Features



\- Student Profile

\- Marks Manager

\- Percentage and Grade Calculation

\- Study Task Manager

\- Add, view, complete and delete tasks

\- Performance Report

\- Input validation

\- Data storage using JSON



\## Requirements



\- Python 3.x

\- No external Python libraries are required.



\## How to Run



1\. Install Python 3.x.

2\. Open the project folder.

3\. Open Command Prompt in the project folder.

4\. Run the following command:



python main.py



5\. Follow the options shown in the main menu.



\## Project Files



\- `main.py` - Main program and menu

\- `marks.py` - Marks and grade management

\- `tasks.py` - Study task management

\- `validation.py` - Input validation

\- `storage.py` - Data storage and retrieval

\- `README.md` - Project documentation



\## Main Menu



1\. Student Profile

2\. Marks Manager

3\. Study Task Manager

4\. Performance Report

5\. Exit



\## Project Purpose



The purpose of this project is to provide a simple command-line application for managing student academic performance and study tasks using Python.
